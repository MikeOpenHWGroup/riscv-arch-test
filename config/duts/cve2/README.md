# ACT4.0 Configuration Files for the OpenHW CVE2

These configurations are specific to the [OpenHW Foundation CORE-V CVE2](https://github.com/openhwgroup/cve2) core.
The configurations are:
- cv32e20 : an RV32IMC machine-mode-only core.
Possible future configurations include:
- cv32e20x : same as the CV32E20 plus the [CORE-V eXtension Interface](https://github.com/openhwgroup/core-v-xif).
- cv32e20u : same as the CV32E20 plus support for Machine and User mode.

## Note: this is a work-in-progress.
As of 2025-12-29, ACT 4.0 supports the unpriviledged specification only.
Changes to this branch/repo are expected.
